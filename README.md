# SARV Infotech Internship Projects

### Web Development Internship | HTML | CSS | JavaScript

A collection of web development projects completed as part of the SARV Infotech internship, including a To-Do List web application and a tribute page dedicated to Dr. A.P.J. Abdul Kalam.

The projects were developed using HTML, CSS, and JavaScript to practice frontend development, user interface design, and interactive web functionality.

---

## Projects

### 1. To-Do List

A web application designed to help users organize and manage tasks through a simple interface.

**Key focus areas:**

* Task management interface
* Interactive frontend functionality
* HTML, CSS, and JavaScript practice

### 2. Dr. A.P.J. Abdul Kalam Tribute Page

A tribute webpage dedicated to Dr. A.P.J. Abdul Kalam, presenting information about his life and legacy through a structured web interface.

**Key focus areas:**

* Webpage layout and styling
* Content presentation
* HTML, CSS, and JavaScript practice

## Getting Started

1. Clone or download this repository.
2. Open the desired project folder.
3. Locate the `index.html` file.
4. Open it in a web browser.

For local development, open the project in Visual Studio Code and use the Live Server extension.
